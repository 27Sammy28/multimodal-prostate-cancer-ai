# Results Directory

Generated experiment outputs belong here.

- `checkpoints/`: trained weights such as `efficientnet_best.pkl`
- `embeddings/`: NumPy, Parquet, or CSV embedding files
- `figures/`: EDA, WSI, mask, stain normalization, UMAP/PCA, ROC, and confusion matrix plots
- `tables/`: metrics and summary CSV files
- `reports/`: generated experiment summaries

Keep large generated files out of Git unless they are intentionally part of a release.
